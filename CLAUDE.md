
# DECIFAZ — PROJECT GUIDELINES

## 1. Sobre o projeto
A Decifaz é uma empresa de tecnologia e soluções
personalizadas. O site deve transmitir profissionalismo,
inovação, clareza e confiança.

## 2. Objetivo
Construir o site institucional seguindo fielmente
os protótipos aprovados no Figma.

## 3. Regras fundamentais
- Não inventar elementos visuais.
- Não alterar o layout sem autorização.
- Não modificar a identidade visual.
- Não criar páginas que não estejam especificadas.
- Não substituir imagens por alternativas genéricas.
- Priorizar fidelidade ao Figma.
- Manter consistência entre todas as páginas.

## 4. Desenvolvimento
- Reutilizar componentes sempre que possível.
- Evitar código duplicado.
- Separar componentes por responsabilidade.
- Priorizar responsividade.
- Manter acessibilidade.
- Não instalar dependências sem necessidade.

## 5. Processo de implementação
Antes de implementar qualquer página:
1. Analisar o protótipo correspondente.
2. Identificar componentes reutilizáveis.
3. Identificar assets necessários.
4. Verificar as regras do design system.
5. Apresentar eventuais dúvidas.

## 6. Validação
Após implementar:
- Comparar com o protótipo.
- Testar desktop e mobile.
- Verificar espaçamentos e tipografia.
- Verificar interações.
- Corrigir diferenças visuais.
